# Языки интерфейса Повода (iOS)

8 языков, как на сайте: **ru** (исходный), en, de, fr, es, pt, it, pl.

- Строки: `App/Localizable.xcstrings` (String Catalog, JSON). Ключ = русский текст из кода.
- Разрешения и имя под иконкой: `App/InfoPlist.xcstrings` (ключи Info.plist: `CFBundleDisplayName`, `CFBundleName`, `NSFaceIDUsageDescription`).
- Язык выбирает iOS по языку телефона. Нет среди 8 → английский (`CFBundleDevelopmentRegion = en` в `Resources/Info.plist`,
  при этом `developmentLanguage: ru` в `project.yml` и `sourceLanguage: ru` в каталогах — исходник русский).
- Сменить язык только для приложения: Настройки iPhone → Повод → Язык. В приложении: настройки → оформление → «язык» (открывает этот экран).
- xcodegen кладёт `App/*.xcstrings` в ресурсы сам (`sources: - App`), Xcode компилирует их в `<язык>.lproj`.

## Правило для новых строк (обязательно)

1. **Пиши строку литералом там, где SwiftUI сам ищет перевод:** `Text("…")`, `Button("…")`, `Label("…", systemImage:)`,
   `.navigationTitle("…")`, `.alert("…")`, `.confirmationDialog("…")`, `TextField("…")`, `Stepper("…")`, тернарник внутри `Text(x ? "a" : "b")`.
2. **Если строка уходит в параметр типа `String`** (тост `store.show(…)`, `Cap(…)`, `SheetBox(title:)`, `SheetOption(title:)`,
   `EmptyState(title:text:action:)`, `HintCard`, `Chip(text:)`, ошибки `err = …`, модели) — **оборачивай: `String(localized: "…")`**.
   `Text(stringVar)` строку НЕ переводит — переводить надо там, где строка создаётся.
3. **Не склеивай фразы из кусков** (`"удалено: " + x`). Числа и имена — интерполяцией в одном литерале:
   `String(localized: "удалено: \(n) подборок")` → ключ `удалено: %lld подборок`. Int → `%lld`, String → `%@`;
   другие типы (Double, Date, Substring) — сначала в String через форматтер.
4. **Множественное число** — одна интерполяция `\(n)` в строке и plural-варианты в каталоге:
   ru и pl — `one / few / many / other`, остальные — `one / other`. Готовая функция `companies(n)` → «3 компании» / “3 companies”.
   `ruCount(…)` — только русский, для интерфейса не использовать.
5. **Даты и числа** — только форматтеры текущего языка: `Fmt.when(d)`, `Fmt.num(n)`, `d.formatted(...)`. Никаких русских месяцев и `Locale("ru_RU")`.
6. **Один и тот же русский текст с разным смыслом** — отдельный ключ: `String(localized: "logo.povod", defaultValue: "повод")`.
7. Знак `%` в тексте → в ключе `%%`.

## Как добавить строки в каталог

```bash
python3 tools/check-xcstrings.py --missing > /root/work-tmp/missing.txt   # список недостающих + JSON-шаблон в конце
# заполни JSON: {"ключ": {"ru": …, "en": …, "de": …, "fr": …, "es": …, "pt": …, "it": …, "pl": …}}, plural — объект форм
python3 tools/xcstrings-add.py new-strings.json          # (--infoplist — для InfoPlist.xcstrings)
python3 tools/check-xcstrings.py                         # должно быть «ошибок: 0»
/root/bin/swift-syntax-check App
```

`tools/check-xcstrings.py` проверяет: JSON читается, у каждого ключа все 8 языков, спецификаторы совпадают по количеству и порядку,
plural-формы полные, все строки интерфейса из кода есть в каталоге (их ищет `tools/swift_strings.py`; если он ошибся с типом
интерполяции — поправь `INT_EXPR`/`STR_EXPR`/`FILE_STR` в нём).
Xcode при сборке в IDE сам допишет найденные в коде ключи — это нормально, но переводы всё равно добавляй сразу.

## Что НЕ переводится (так и задумано)

- Данные с сервера: названия компаний, ниши, города, тексты писем и сообщений, названия рассылок и баз, тариф (`planName`).
- **Ошибки API с сервера** (`{"error": "…"}`) — приходят по-русски и показываются как есть. Переводятся только свои
  запасные тексты приложения (`API.errorText`, `friendly()`). Заголовок `Accept-Language: ru` не менялся.
- Фикстуры снимков CI (`Fixture.swift`, `MailStore.fill`) — это «данные».
